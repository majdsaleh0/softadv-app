# LocalEase

A Flutter/Supabase mobile marketplace connecting customers with local independent
service providers — home repair, tutoring, cleaning, beauty, and similar — through
search, booking, reviews, and in-app messaging.

## Stack

- **Client:** Flutter (Dart)
- **Backend:** Supabase (Postgres, Auth, Storage, Edge Functions)

## Getting started

1. Copy `.env.example` to `.env` and fill in your Supabase project URL and anon key.
2. `flutter pub get`
3. `flutter run`
